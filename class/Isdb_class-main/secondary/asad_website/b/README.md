# Arc Estate Demo

A premium real estate website starter built with PHP, Bootstrap 5, and JavaScript.

## Run locally

Use PHP's built-in server:

```bash
php -S localhost:8000
```

Then open `http://localhost:8000/index.php`.

## Includes
- Homepage with search and featured listings
- Property detail modal
- Wishlist toggle
- Currency switcher
- Contact form handler
- Responsive Arc-style UI
