# Fly Soul v3

Original navy/gray premium travel website starter built with PHP, Bootstrap 5, CSS, and JavaScript.

## What works
- Home page with original premium layout
- Destinations, experiences, booking, offers, services, about, blog, contact
- Search form that filters destinations
- Booking flow with payment methods
- Service booking forms for:
  - Hotels
  - Tours & activities
  - Chauffeur-drive
  - Meet & Greet assistance
  - Airport transfers
- SQLite storage for bookings, service requests, and contact messages
- Mobile-friendly responsive UI

## Run
1. Put this folder in your PHP server root
2. Make sure `storage/` is writable
3. Open `index.php`

## Payment note
This starter captures payment method choice and transaction/reference ID.
You can connect real gateways later for live card and wallet checkout.
