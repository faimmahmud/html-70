# Event Management System

A clean MVC PHP starter with:
- Strict OOP PHP
- SQLite storage
- Secure registration
- Premium landing page
- Responsive navbar
- CSRF protection
- Flash messages

## Requirements
- PHP 8.1+ recommended
- PDO SQLite enabled

## Run locally
From the project root:

```bash
php -S localhost:8000 -t public
```

Then open:
- Home: `/`
- Registration: `/register`

## Notes
- The app uses SQLite, so it runs without MySQL setup.
- Database file is created automatically in `storage/app.sqlite`.
