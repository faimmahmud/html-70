Arc Travel Website Starter

Files:
- index.php
- data.php
- style.css
- script.js
- submit_booking.php

Run locally:
1. Put the folder in your XAMPP htdocs or similar PHP server directory.
2. Open http://localhost/tourism_website_fixed/index.php

Notes:
- Bootstrap is loaded from CDN.
- Images use Unsplash URLs, so internet is needed for images.
- Search, category filter, price filter, modal details, and booking form are all working.
